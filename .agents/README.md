# .agents

This folder contains reusable AI engineering context for this repository.

## Folders

- `prompts/` contains reusable prompts for planning, implementation, debugging, and review.
- `checklists/` contains review checklists used before accepting AI-generated code.
- `skills/` contains Codex skills using `SKILL.md`.

## Rule

Keep this folder small. Do not store random notes, secrets, personal data, generated logs, or project-specific temporary ideas here.

Use `AGENTS.md` for permanent engineering rules.
Use `/docs/ai-activity/` for activity logs and implementation notes.
