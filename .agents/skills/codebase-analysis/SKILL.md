# Codebase Analysis Skill

When analyzing a codebase:

1. Inspect the existing folder structure.
2. Identify the main entry points.
3. Identify the relevant files for the task.
4. Understand naming conventions and code style.
5. Look for reusable modules before suggesting new ones.
6. Avoid broad rewrites.
7. Explain the current flow before implementation.
8. Suggest the smallest safe change.
9. Flag oversized files, duplicated logic, dead code, and risky patterns.
10. Return a concise plan before editing.
